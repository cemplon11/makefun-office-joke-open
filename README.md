One office joke, single line, for The Office Joke Open: our "efficient"
daily standup eats 45 minutes explaining why yesterday's 15-minute
standup ran long — while Jira still lists the ticket as "in progress"
since March. The program is pure-stdlib Python and writes that one
line, deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
